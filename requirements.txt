# The gateway's one runtime dependency, and the reason the product stopped being
# stdlib-only (AGENTS.md records the exception and what it costs).
#
# `mcp` is the official Model Context Protocol Python SDK. It owns the protocol and wire
# layer this product used to hand-write: which revisions exist, how the 2025 `initialize`
# handshake negotiates one, how the 2026-07-28 per-request envelope and `server/discover`
# work, and how both are served from a single `/mcp`. Nothing product-facing is imported
# from it -- no coaching, no store, no validation, no provider access -- and no LLM API
# comes with it, so AGENTS.md's first rule is untouched.
#
# Pinned exactly, not floated. This dependency decides what a connected client sees on
# the wire, so which version a deployment is running has to be a fact in the repository
# rather than whatever the build host resolved that day; `/readyz` reports the resolved
# version beside the release identity.
mcp==2.2.0

# This file is the *intent*: one name, one version, and the reason. It is not what any
# build installs. `requirements.lock` is -- it resolves this pin to every distribution
# that can enter the gateway image, each with the sha256 of the artifacts allowed to
# satisfy it, and every install site passes `--require-hashes` so a substituted byte
# fails the build instead of shipping. A version number is not an artifact identity; a
# hash is. Regenerating the lock is step 2 of the upgrade ceremony in
# docs/ops/upgrade-the-mcp-sdk.md, which is also where the trigger for upgrading at all
# is written down.
