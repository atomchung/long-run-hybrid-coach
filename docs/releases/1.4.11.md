# 1.4.11 — the OpenAI directory reviews the Plugin entry

The first version submitted for the Plugin entry: a second deployment of the same code
with its own store and its health data switch `off` (PR #523, issue #519). 1.4.10 was
rejected for healthcare scope on 2026-10-02; this submission is a different product
surface, not the same one resubmitted.

Priority: **Current** — OpenAI distribution is blocked (issue #519). Patch bump, per
AGENTS.md "Version numbers": the number is new because the submission is, not because
the full product changed.

## Before → after, in user terms

| | 1.4.10 submission | 1.4.11 submission |
| --- | --- | --- |
| MCP URL the reviewer connects to | the full product | the Plugin deployment |
| Intervals permissions requested | activity, wellness, calendar and settings | activity, calendar and settings; no wellness permission |
| What the listing says is processed | activities, sleep, HRV, resting heart rate, body measurements, symptoms | completed activities and what the athlete chooses to tell it |
| Reviewer record case | saves a weight, sleep, HRV and resting heart rate | saves strength sets and a note about how the athlete feels |
| `startCoachSession` scans as | destructive (it could replace stored readings) | not destructive (it stores none) |

For the full product nothing changes but the version number it reports. Production may
stay on 1.4.10 until the next roll; the Plugin deployment is what has to serve 1.4.11
before Scan Tools.

The Plugin's OAuth discovery and authorization redirect both use the reduced scope set,
including for clients requesting the older four-scope set. This changes no existing
provider grant and adds no confirmation step. A future capability requiring more access
needs a new authorization for connections lacking that access; its notice and
reauthorization flow are separate work.

  import `chatgpt-app-submission.training.json`. The steps are in

  and discovery before release; the local HTTP regressions use a fake provider.

  roll; it does not block this submission.
